# @retrieval-agent/agent-plugin

DSH 模型、工具、上下文的产品接线；数据库模式包含 MySQL 权威任务、幂等命令、租约与事件提交、后台 Wiki 提炼/来源校验和文件增量发布，以及可修复的 Session 镜像。主 Agent、专家与算子用量复用 DSH 官方统计投影并汇总到任务；上下文压力、压缩状态和历史整理也通过同一工作台展示。Session 技术预览为独立兼容模式。

公共入口、依赖和构建脚本由 [package.json](package.json) 声明。产品语义见 [产品规格](../../docs/PRODUCT_REQUIREMENTS.md)，组件关系见 [架构说明](../../docs/ARCHITECTURE.md)。
