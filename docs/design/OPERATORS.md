# Python 语义算子与现有 Host

语义入口只有 `sem_filter`、`sem_extract`、`sem_agg`。搜索和读取是基础工具；确定性集合运算、排序和统计由普通代码执行。一次任务只需要 filter 时不执行抽取或聚合。Python 使用现有 DSH 模型回调，不创建第二个 Agent、标签服务或质量 Agent。

| 入口 | 输入与结果 | 使用边界 |
| --- | --- | --- |
| sem_filter | 完整业务判据与当前召回候选并集 → 确认集合及质量对象 | 默认对关键词 OR 全部字面命中与语义召回结果按工单身份去重后的并集学习筛选；显式指定候选或示例任务可直接判断少量记录 |
| sem_extract | 明确所需记录、字段/schema → 有字段来源的事实 | 字段读取和可靠解析优先；开放事实通过现有 DSH reader，不按簇传播金额、日期或原因 |
| sem_agg | 所给事实/证据 → 代码统计与有来源的说明 | 证据窗口不改变集合；总体精确统计必须有全部所需字段 |

`sem_map`、`sem_topk`、`sem_join` 已退出生产工具、计划、Python 分发和实现。新的关系任务有明确需求后再设计；排名不能决定全集成员。

## 默认执行路径

`工作台任务 → task-worker/pre-step/sem_filter 工具 → SemanticOperators.filter → PythonOperatorBridge → server.Bridge.execute → invoke_rows → filter.sem_filter → filter.learned_filter`。

`auto` 和 `learned` 进入同一学习主干，`active` 是已有配置消费者的薄别名。无明确示例数量时，对关键词 OR 全部字面命中与语义召回结果的去重并集进行学习筛选；这里的“召回全集”不包含未进入并集的授权工单。`direct` 仅为显式小范围参照；`baseline/cluster` 按需加载独立 `baseline.py`，保留旧区域算法用于迁移对照，不是失败回退。缺少数值 Provider 时默认召回并集筛选报错，不逐条强判。

Python 包的模块按职责收敛：三个算子各一文件，模型与数值块各一文件；`search.py` 保留现有一次规划与检索回调，`runtime.py` 统一模型回调、缓存和计量，`server.py` 共用 stdio/WebSocket 服务。抽样归入 `features.py`，证据选择归入 `aggregate.py`，分发直接位于包入口。没有独立 JSONL、embedding 或 HTTP 模型适配，也没有第二套 Python 启动编排。

Python `Runtime.call` 只覆盖 `query_plan`、`sem_filter`、`sem_extract`、`sem_agg` 的模型回调；收到明确可重试的传输/超时/限流/服务端错误，或模型 JSON 结构缺少必填字段、不符合输出 schema（`OUTPUT_SCHEMA`）时，对该逻辑请求最多执行三次物理尝试，即首次加最多两次重试。默认等待 1 秒、2 秒；供应商给出更长等待提示时优先采用，但单次最多等 30 秒。每次尝试有独立调用 ID、DSH 清单和回执，实际失败、成功与 token 用量均分别计量；每次尝试前重新核验作用域，取消会打断等待。凭据、模型配置、额度等明确永久错误及未知错误不重试。JSON schema 重试不放宽引用身份、证据或业务校验；查询规划中部分计划约束另有一次带校验原因的修正机会。筛选的 128 次上限只计 `auto/learned/active` 学习流程中的独立初判与命中复核请求，逻辑请求的首次尝试占一个额度，自动重试和缓存命中不另占额度；最多三次的每次物理尝试仍计入调用、失败和用量。该策略不是主 Agent、最终报告或所有模型调用的通用重试规则；Python 请求耗尽后返回终态错误，由 Host 结束本轮为未完成并保留确认结果，不自动重新执行整份检索作业。

模型负责判据、歧义、相关性与语义停止。Host 负责当前输入代次、授权来源、真实引用与结果发布。完整自然语言要求来自现有一次 query 理解；关键词 OR 分支完整枚举全部字面命中，语义召回分支按检索配置取结果，两者去重并集才是默认学习与预测范围。召回表达只用于发现训练样本，不替代业务判据。只有标题和摘要时按实际可见事实判断，缺少判据所需事实保持未知。

同一次查询规划负责知识路由：检索 Agent 接收固定版本 Wiki 的领域目录、条目标题、适用范围与关键词，返回 `knowledge_routes`（条目 ID、业务选择理由）。规划阶段不自动注入知识正文；抽样判断和复核只加载选中条目的正文，空路由执行零样本判断。页面展示选择和理由；“专家与知识”还按实际 DSH 样本请求显示所携带的知识、请求次数与去重工单数，支持打开正文，独立于是否调用领域专家。没有路由的历史计划在再次执行时补做规划，不沿用固定前三条的词面搜索结果。

规划上下文区分 `search_fields`（搜索索引名）与 `evidence_fields`（可读的 L2/L3 来源字段）；后者排除摘要、生成字段、不可用字段与原始 JSON 载荷。`required_fields` 必须来自后者；旧计划要求了不可读原文字段时重新规划，不能因摘要被误列为原文而反复产生未决判断。用户明确要求但来源缺失的原文仍保持未决，不自动换成摘要。

规划不把 Wiki 的取证建议升级成用户未提出的必要条件；判断时逐项核对用户明确的对象、原状态、变化及时序。部分条件有据而其他条件未被说明时保持未定，不能用相似主题、日期或行业惯例补足，也不能为凑足示例数量放宽条件。示例任务的关键词全集按 100 条一页枚举，模型审阅窗口和原句向量 Top-K 独立配置。

强模型初判命中的记录在提交前另做一次缺项复核，只传用户判据与该记录材料，不传初判标签或理由。复核独立说明每项必要事实的依据或缺项，缺项保持未定；最终标签与引用来自复核请求。它不是投票或置信度门槛，新增调用如实计量；排除和未定记录不重复复核。

后续重读同时携带该工单上一次的未解决疑点。它不是来源事实或新的纳入要求；改为确认时必须说明新增材料如何解决疑点，或指出先前疑点与原文的具体矛盾，不能靠重复抽样改判。对话中的新推荐方案与原先状态分别理解，指代或转写歧义无法消除时保持未定。

编号核验可要求已有 `displayId`，其存在性与业务原文存在性分别判断；编号字段不能单独证明任何业务事实。

启用算子时，`ticket_decide` 只接收当前明确专家分歧的主 Agent 判断；普通候选通过 `sem_filter` 或读证后的自动筛选提交。主 Agent 不能绕过算子把缺项结果改成确认，充分时用空 judgments 提交结束动作。

明确数量的示例任务每次自动筛选只处理一个尚未判断的审阅窗口，然后交回主 Agent。已经未定的记录不因再次调用而自动重判；主 Agent 可定向读证后复核、继续下一窗口或搜索新表达。窗口结束不改变任务的未完成状态，不是总调用、时间或 token 限额，也不代表要求已满足。未给数量时，对当前关键词与语义召回去重并集执行学习式筛选。

## 数值输入与持久集合

- `featureBlock` 返回召回并集内对齐整数 IDs、连续 little-endian float32 稠密块、availability，以及可选 CSR 列块；正文不随特征读取传输。`features.take` 按小块读取有界样本池，`rows.read` 仅按标注或问答证据 IDs 读正文。
- 数据库索引准备阶段的 `prepareNumericFeatures` 将既有 Milvus 分片向量按工单聚合、归一化一次，批量写 `ra_numeric_feature`。缺向量仍保留 ID 和缺失标记。现有索引执行 `node scripts/database.mjs index` 补齐数值列；新数据执行 `pnpm db:prepare`。Provider 检查数值索引覆盖，不在查询中重建 embedding。
- 数据库 Provider 以授权 SQL 范围和数值键分页，默认 Host 传输批宽上限 2048；Python 本地可使用只读 memmap 块。当前生产表示是稠密 embedding，只有 Provider 真正提供 CSR 时才比较稀疏 SVM，不复制一套稠密向量冒充多表示。
- `predictions.begin/write/finish` 复用一份模型与质量说明。每块输出 IDs/labels/scores，`MySqlSemanticResultStore` 批量写已接受 ID，任务状态仅持有模型/集合句柄；数值结果不构造逐条 LLM 清单或重复指标报告。
- 确认页、报告计数、CSV/JSONL 下载使用同一集合句柄。分页时才映射真实工单 ID 并重新授权；报告保存有明确口径的集合哈希。点击原文和反馈只水合所需记录。新查询代次及强标签更正使旧句柄失效。

非持久示例会话使用内存集合存储，只用于小数据接线。不能据此声称跨进程恢复或 4000 万条容量。生产持久任务使用现有 MySQL TaskStore 的集合表。

## 学习、选择与直接预测

1. 查询规划完成后，关键词和向量通道并行执行；首批候选及进度可先显示，完整关键词枚举与语义召回都结束后才固定去重并集并启动数值学习。学习范围是关键词 OR 全部命中和语义召回结果按稳定工单身份去重后的并集；不把首屏或部分召回当作训练、选择或预测总体。关键词分支枚举全部字面命中，语义分支遵循检索配置。并集 ID 留在数据侧，任务只接收首批展示/种子窗口，正文按标注与查看需要读取。仅对并集 ID 计算排序特征：查询字符 2-gram 在工单索引中的覆盖率与非负向量余弦相似度等权平均。查询向量复用已有 embedding 缓存；词面覆盖复用 gram 索引，未建索引时在数据库搜索字段上计算，只向算子返回数值。
   有界候选池按相关分数降序保留，并与该召回并集中的种子合并；训练、扩充和模型选择都从前往后标注，分数相同时按 ID 稳定排序，不混入随机或 K-means++ 样本，也不在读取正文前重新按 ID 打乱。默认每个发现标注窗口 128 条，按排序一起读取训练和留出候选；排名只决定先判断哪条，不能作为业务标签。未决样本不计入有效训练样本，二分类训练需要实际正反例。
   一组待标注样本先合并读取正文，再按配置的模型批宽并行判断；例如并发 32、批宽 4 时，同组最多读取 128 条样本，发出至多 32 个各含 4 条样本的模型请求。尾批和命中复核可少于批宽。
2. 同一训练集实际拟合 scikit-learn LR、LinearSVC、浅 MLP、浅 HGB。稀疏表示存在时 SVM 使用 CSR。训练类别平衡权重不代替总体采样权重。未知标签不训练为负例；单类先扩大一次表达发现，仍不足则返回具体缺口。
3. 训练与选择按排序交错留出，保证两者都有机会取得靠前的候选，且 ID 不重叠。首次拟合前，若某类已有至少两条却全落在一侧，按排名移一条到缺类的一侧；模型一旦拟合，续补选择集不改变原训练成员。单个正例不能同时用于训练和选择。选择集用于模型及阈值选择，只报告该集合的经验质量，不能代表总体分布。选取经验质量合格候选中估计执行成本较低者，分数不跨模型平均、不当概率证书。线性模型等价折叠标准化；保留训练精度，不默认量化。小标签集可用有界 worker，内部 BLAS 线程受限。
4. `auto/learned/active` 学习筛选中的抽样初判与命中复核共用每个查询条件代次最多 128 次独立判断请求；此额度不限制查询规划、抽取、聚合或其他主 Agent 模型请求。首次尝试即占用一个逻辑额度，自动重试与缓存命中不重复占用，但每个物理尝试均有独立计量。主机/进程恢复和用户显式续跑沿用同一查询条件代次、学习状态与额度，不重置上限；输入条件变更后才进入新代次。训练样本用于拟合，互不重叠的选择样本用于选模型和阈值；样本数量随标签分布、未决比例及达标情况变化，不是固定配额。没有选择集达标候选且尚有额度时，按相同顺序补充标注并重新比较；保留历轮最佳模型。仍未达原目标时按选择集 F1 选最佳者，查准率至少 60% 才可预测，否则返回 `model_unknown`。额度用尽且缺少可训练类别或有效选择指标也返回 `model_unknown`；最后一次初判的命中尚未复核时保持未决。
5. 选择集达标或最佳模型达到 60% 查准率门槛后冻结模型和阈值，只对本代关键词与语义召回去重并集数值预测。已有正反例与未决标签覆盖预测，缺特征保持未知；不再建立独立随机样本、读取抽验正文或调用大模型。四个模型共用一套训练与选择标签。
6. 新结果的质量说明使用 `basis=selection`、`precision`、`recall`、目标和选择样本数量。默认选择集 P/R 目标均为 .95，可配置；不输出总体查准率/召回率下界。未知选择标签不参与二分类指标，数量单独披露。选择指标用于模型与阈值选择，不等于真实业务质量，也不代表召回并集外工单的查全情况。
7. `quality_passed` 表示选择集达标，`quality_fallback` 表示未达原目标而采用最佳模型，两者均已完成召回并集预测。质量对象用 `acceptance=target/fallback` 区分，Host 同时核验选择集查准率至少 60%。`model_unknown` 显示“不知道”，Host 以未完成结束，页面、报告、下载和重放只返回已有明确确认结果。已有任务的旧抽验指标只保留为历史记录，不重新触发抽验；旧 `validation_size`/`delta` 配置在默认学习路径忽略，显式旧 baseline 配置不变。

有额度时按 `next_action` 补充具体证据或类别覆盖；`model_unknown` 的下一动作固定为 `return_confirmed_only`，不能用定向 direct 判断绕过额度。输入没有变化且已交付或无法判断时不重复过滤。抽样上限不作为语义完成证明，也没有隐式全量 teacher 回退。

主机恢复与显式续跑复用当前查询代次中的有界排序 ID 池、小模型学习检查点、已提交判断和持久结果集合，不复制或重新发现未变更来源的召回并集。`needs_selection_coverage` 保留原训练/选择划分，继续从当前召回并集中未判且未训练的排序池补选择样本，不重新判断并集外工单；新增召回种子按相关分数合入。新选择样本用于经验选模，达标后直接预测，不再独立抽验。查询、授权、召回范围、来源数值版本或学习配置改变会失效相应缓存；已有训练标签更正时重训。未决样本按原文及证据要求辨识，相同材料不再次请求模型；补充原文后恢复判断。传输并发和批宽变化不清除训练成果。主 Agent 可直接调用筛选续补选择集，无需先补搜；召回并集耗尽仍缺类时返回 `needs_coverage`，要求解决发现缺口。

样本判断提示词只包括简短系统指令与原始查询/用户补充、当前批次工单、选中知识的标题/正文和结构化输出要求。知识发布元数据留在回执，不进入模型提示；检索规划的改写不重复作为判断条件。输出使用三态标签、简短理由和原文引用，命中复核只增加一句独立核对要求。判断行的附加说明字段不参与业务判断，也不中断筛选；标签、工单身份和来源引用仍按实际证据检查。

## 抽取与问答

`sem_extract(field_map=...)` 直接解析已送达的来源字段，缺失或不可解析时返回 undetermined；先用 `ticket_read` 取得确实需要的字段。开放事实调用实际 DSH reader，非空字段各有引用，不沿相似关系复制事实。

`sem_agg(numeric_fields=...)` 先统计所给记录的 present/missing/observed_sum。缺字段时不生成精确 sum/mean；代码结果和覆盖口径送入实际 DSH writer。当前该接口统计命名输入记录，未自动扫描任意整个确认集合的所有业务字段；局部字段结果不能冒充总体精确统计。

`evidence_window` 仅对已确认、命名的有界证据池执行 MMR 多样性选择。池内相关性已由 filter 判定，窗口按等相关度选择不同向量；不将模型分数当概率。返回 `selected_evidence_only` 与 Host 提供的总体数量，不截断 filter 集合。需要针对新问题更相关的池时，先用现有 search/read 取得所需证据。

分层摘要只传子摘要、来源 ID 和父关系；独立索引保存叶证据，最后物化所引用叶子的来源。最终引用列表仍随所引用证据量增长，当前证据窗口用于控制解释规模，不能把局部摘要宣称为全部记录的事实统计。

[评测策略](../EVALUATION_STRATEGY.md) 区分静态审查、数值等价、受控合成质量、真实模型/中文业务、完整 Agent 端到端和 40M 冷热 I/O。公开 DSH 工具加实际 Python 的测试证明接线，但脚本 teacher 不是真实模型。MySQL/Milvus 批写、重启恢复与容量必须在对应服务和数据上实测。运行入口见 [Python README](../../python/semantic-operators/README.md) 和 [开发说明](../DEVELOPMENT.md)。
