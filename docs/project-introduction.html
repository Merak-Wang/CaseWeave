03 / CONTEXT BY DESIGN

工单可以很多。
每一轮，只带入此刻所需。

完整候选与证据保存在数据层。上下文规划器为主 Agent 和各领域专家分别安排工作视窗，按需展开 L0–L3，避免历史工单逐轮堆满模型上下文。

  • 01当前轮展开标题、摘要及必要证据；旧轮保留决定、缺口与少量定位引用。
  • 02需要早期线索时，按稳定身份重新读取原文，压缩摘要不替代原始证据。
  • 03随模型容量调整预算与片段大小，用户条件和关键反证始终保留。

05 / LEARN, VERIFY, IMPROVE

让下一次检索，带着经验出发。

Wiki 是可维护的领域先验。自动学习建立在可追溯的反馈处置和检索证据之上，校验后的知识可用于后续判断，效果通过任务对照评估。

01 / OBSERVE

收集反馈与轨迹

用户补充、相关性反馈及成功或失败的检索经验进入任务记录。

02 / VERIFY

复核、提炼与校验

Agent 复核反馈，核对证据、反例与适用范围，形成有来源的知识增量。

03 / RELEASE

自动发布新版本

增量写入目录化 Markdown / 结构化 Wiki，通过自动校验后发布，保留回退能力。

04 / REUSE

后续任务直接复用

专家引用新版先验调整策略；当前任务固定知识版本，当前证据仍可否定旧经验。

用户的“相关 / 不相关”是复核输入，由 Agent 结合证据决定。错误经验可以修订或停用，当前证据始终优先。

  • ✓
    结论连接原始证据
