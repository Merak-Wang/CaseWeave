# Retrieval Agent 评测与验收策略

本文定义产品行为、检索质量和部署可靠性的验证方法。场景定义不代表已经通过；执行命令见 [开发与运行](DEVELOPMENT.md)。

## 1. 被测边界与证据

产品经公开入口接收自然语言、用户补充和反馈，产生状态、报告与下载。评测不能另写一套 Agent loop，也不能把正确 filters、qrels、Gold、oracle 或评分器注入生产运行时帮助答对。

| 证据 | 可以说明 | 不能直接说明 |
| --- | --- | --- |
| 文档/源码核对 | 设计、接口与调用点存在或冲突 | 实际已接通、性能或业务质量 |
| 组件/契约测试 | 给定边界输入的确定性行为 | 真实 Agent 的语义质量 |
| 公开入口的受控纵切 | 输入、工具、状态、UI/导出/重放接线 | 替身作出的相关性判断正确 |
| 指定模型真实 Agent 任务 | 该模型、数据、Wiki 与配置下实际行为 | 全部场景、较小模型或真实业务库都正确 |
| 真实数据库/浏览器/恢复验收 | 对应实际依赖和生命周期行为 | 超出本环境的生产可靠性 |

Provider 的 embedding 排名、服务健康状态和工程检查分别反映局部能力，真实 Agent 的业务判断需要独立任务评估。

## 模型容器部署验收

部署变化复用 A1/A4/A7/A8/A12/A14，不另造 Agent loop。先保存原模型服务的协议、模型/词表/来源/索引身份、查询分析、实际向量和快查集合，再对 CPU/GPU 执行同一请求。当前跨设备预设容差为每条 L2 向量 cosine≥0.999、最大坐标差≤0.005、候选 Jaccard≥0.9；分析语义、关键词数量、发布身份必须一致，候选增减逐项保存。阈值不是业务 Recall 或可通用的模型质量线，失败先保留差异，不事后放宽标准。

容器就绪、真实向量、完整任务分别验收：缺模型/校验失败不得 ready，显式 GPU 不可用不得降级，Node 退出不停止 Docker 服务；首次容器内下载、只读导入、重复准备、离线读取、请求取消和持久缓存重启需有实际证据。公开 `/retrieval` 任务的独立预期只保存在验收端，读取原文后确认，报告/下载/恢复核对同一结果身份。新机器声明还需要没有 Python/uv 的干净宿主完整安装和跨版本升级/回退；本机删减 PATH、新卷或 mock 仅证明各自有限范围。运行入口见开发说明，结果应保留对应环境与命令信息。

## 2. 行为矩阵

| ID | 场景 | 公共入口应观察的结果 |
| --- | --- | --- |
| A1 | 快查与简单任务 | 原句解析后真实关键词/向量并行；首批候选可见；不首轮语义扩写；简单问题不强制多专家 |
| A2 | 业务条件、布尔和数量 | 普通主题“和/与”默认 OR，明确 AND/同时出现取交集；嵌套 OR/NOT、字面/语义排除、日期/空值；用户修订后旧资格失效；全集不被 Top-K/页宽截断 |
| A3 | 相关性与确认 | 有证据地确认/排除；没读到的工单不自动接受；当前集合与历史分离 |
| A4 | L0–L3 取证 | 标题/摘要足以判定时直接提交，原文只为具体疑点或用户核实需求读取；实际模型可见、用户可见和来源身份分别记录；报告/下载/replay 引用一致 |
| A5 | 澄清与反馈 | 工具发问→公开用户回复→原任务接续；举例/引文不变地域过滤、不重复首轮；明确移除条件同时修订 AST；普通业务口径自决，已回答问题不重复询问 |
| A6 | 可选先验 | 无 Wiki 零样本完成；先验不能造工单；当前证据可否定知识 |
| A7 | 运行边界和当前访问 | 取消、服务失败、容量、旧引用/过期来源具体处理；迟到结果不覆盖新状态；历史不恢复访问权 |
| A8 | 终态和重放 | 枚举边界、语义充分、运行中止分开；最终只交付确认结果；旧版本可追溯、恢复一致 |
| A9 | 多专家协作 | 委派立即返回，专家运行时主 Agent 可独立工作、逐个合并发现；事件等待首个相关结果；不同分工追加、重复分工拒绝；迟到分歧重新打开判断，旧代次拒收 |
| A10 | 大集合与压缩 | 千级候选外置；8 轮轨迹预算受控；早期关键证据可重读；不丢否定/反例和长期未判候选 |
| A11 | 自动 Wiki 学习 | 反馈复核→增量→自动校验发布→新任务实际消费；错误反例修订/回退；无人工审批 |
| A12 | MySQL/Milvus | JSONL 导入、SQL 字面全集对照、真实向量调用、索引版本/水位、更新/删除/滞后处理 |
| A13 | 后台与全双工 | 慢 I/O 时反馈可持久回执；关闭/刷新/断线返回仍能恢复；Host 重启无重复提交，问题不丢 |
| A14 | 报告和下载 | 引用确认集合，模板数字源于状态；数千条完整下载；手传未确认 ID 拒绝，失效来源明确报错 |

A2 必须检查最终集合，不只看 SQL；A4 检查实际 ContextManifest 和引用，不只看 HTTP 日志；A5/A13 从真实工具与用户通道串起；A11 检查下一任务模型实际收到新条目，不能仅检查文件已写。

## 3. 数据与标签

ESFT JSONL 用于示例和流程验证。用其字面匹配全集建立确定性 oracle，但不能用关键词出现、自动生成 title/category/product 或 Agent 自评制造语义 Gold。缺失时间/地区/状态不补造，相关契约先用显式字段的受控 fixture 验收。

语义样例覆盖：跨字段关系、受理部门偶然提词、客户否认办理、问题与处理结论相反、不同产品同一故障文本、无相关结果、需要深读和用户补充。保留来源片段、标签依据及争议。小样本可以起步，不以凑固定 Gold 数量阻塞研发。

只有在标注覆盖完整、范围明确的集合上报告 Recall；抽样或不完全标签报告已评范围的指标和未判范围。相关性评估以当前 query 的业务含义为准，不能把工单描述中的根因当作已证实的真实根因。

## 4. 质量、性能与成本

| 维度 | 测量定义 | 使用方式 |
| --- | --- | --- |
| 确认精度 | 标注范围内正确确认 / 已评确认 | 优先防误交付；空集合不伪装为满分 |
| 召回/遗漏 | 有完整标签时正确确认 / 应相关全集 | 分首轮候选与最终确认，解释 Agent 新增或丢失 |
| 条件正确性 | 各布尔/字段/修订用例的集合差异 | 明确违反用户要求是失败，不被平均分抵消 |
| 证据与报告正确性 | 引用可定位、支持表述、身份/范围一致 | 工程引用正确和语义支持分别检查 |
| 有效首屏时间 | 提交被接受到第一批可用候选进入 UI | 模型/索引已就绪与冷启动分开测 |
| 反馈响应 | 提交到持久回执，以及到复核完成 | 两个时间分开，防回执快但永不处理 |
| 检索时长 | 首批、最后有效新增、最终报告各时间 | 等人类回答、排队/计算和学习尾部单独记录 |
| 资源 | 各角色 token、调用数、并发、峰值内存、取消后占用 | 比较专家/压缩/索引带来的单位收益 |
| 知识收益 | 留出任务的精度/遗漏/代价变化、错误泛化与回退 | 不以新增 Wiki 条数当效果指标 |

复杂任务的体验目标为约 1～3 分钟持续有有效进展。首屏先以“预热且单任务环境下 p95 不超过 3 秒”、反馈持久回执 p95 不超过 1 秒作为**待测工程假设**；样本不足时只报逐次数据，不冒称可靠 p95。硬件/并发或解析方案不满足时定位并优化，重新记录目标适用范围，不默默扩大时间也不削弱确认要求。

业务精度/召回的发布阈值在代表性样本与试用后确定；当前不凭空规定一个漂亮百分比。没有校准数据不展示概率置信度。

## 5. 对照与学习评测

至少比较快查候选、通用 Agent、带专家/Wiki 的最终结果，明确任务是否真的需要专家。根据变更选择单变量实验：关键词/向量/融合，摘要/片段索引，有无 rerank，不压缩/结构化压缩/模型摘要。不要一次改变模型、数据、prompt 和索引后归因某个模块。

自动学习按时间拆分学习轨迹与留出任务，对照无 Wiki、冻结 Wiki、演进 Wiki。同一反馈在未来被否定时检查旧条目失效与回退；加入误标、重复来源、无可靠结果、发布中断和并发修改。评测用人工标注不会进入在线 Wiki，不设生产人工审批。

在实际采用的每种模型上分别运行自然语言任务，记录实际模型标识、量化/上下文/采样设置与工具错误。真实目标模型未可用时明确留待验证，不用大模型成功替代。

## 6. 检查触发与记录

文档变化做内容一致性、链接与 diff 检查，不默认跑应用全集。行为变化先有可执行失败/期望，再跑对应 A 场景；schema、并发、恢复、来源变化加入旧结果/重复提交/撤权等负例。真实数据库接入需真实服务测试，页面生命周期变化需真实浏览器。包/安装变更才触发相应发布闭包检查，不每次下载模型或数据。

复用已有 TS/Python 设施；公开任务的薄驱动为 `pnpm accept:task`，通过实际 HTTP 接口保存查询、详情、终态和 CSV，独立期望只在验收端比较。当前驱动覆盖查询与交付主线，交互、恢复和领域质量仍选相应真实场景，不为评测创造第二套运行时。LLM judge 可以辅助但须核对其依据和误差，不当唯一真值。

默认自动化保留有明确用户损失的边界：确认准入、来源/授权、旧结果、条件修订、幂等、迟到结果与恢复。删去已由更直接入口覆盖的手造成功链路和装饰措辞断言，不要求实现文件配一份测试。全量语料验证复用数据管理命令，旧 Bronze 假排名不进入默认回归，100 轮重放规模按格式/性能变更显式运行。测试规模与包数不设固定比例门槛；新增验收先寻找可替代的重复覆盖。

每次评测记录代码版本、配置差异、实际命令、数据/模型/索引/Wiki 身份、硬件与并发、输入与期望、观察结果及未验证范围。脱敏轨迹与工件哈希用于复现，质量结论只覆盖这些证据支持的范围。
