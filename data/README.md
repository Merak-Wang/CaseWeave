# 示例数据

默认数据集使用 [manifest.json](manifest.json) 声明的 ESFT JSONL，供单机试用和检索流程验证。来源版本、文件哈希、字段生成方式与数据使用信息以清单为准。

| 目录 | 内容 |
| --- | --- |
| `raw/` | 下载的原始数据 |
| `tickets/` | 转换后的可检索工单 |
| `evals/` | 评测定义、样本及派生数据 |

在项目根目录运行 `pnpm data:sync`，可下载、转换并校验数据。完整容器安装会执行对应准备步骤，日常启动复用现有数据；详细命令见 [开发与运行](../docs/DEVELOPMENT.md)。

默认工单共 19,587 条，日期、地区和状态字段为空。规则生成的产品、类别与摘要不是独立业务真值，不能补足原文中不存在的事实。业务数据可通过 Provider 适配接入，接入后需要验证字段映射、查询语义和检索效果。

下载数据与派生工单保存在本地，按清单重建。测试所需的固定样本与评测定义随源码提供。运行时 L0–L3 的证据层级见 [上下文设计](../docs/design/CONTEXT.md)。
